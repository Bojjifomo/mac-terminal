Trackpad

Klik akurat: di trackpad, geser pelan / diam sebentar = kaca pembesar muncul, tanda + = titik yang diklik. Di layar: tahan jari sebentar, geser buat ngepas (kaca muncul di atas jari), lepas = klik.

Tap ⌘ ⌥ ⌃ ⇧ sekali = buat tombol berikutnya. Tap dua kali / tahan = dikunci (buat ⌘+Tab: kunci ⌘, tap Tab, tap ⌘ lagi). fn + panah = Home/End/PgUp/PgDn, fn + ⌫ = Delete maju.
